📦 NepalCan Follow-up Engine — User Guide

A simple, plain-English guide to the app the team uses to call customers and vendors about orders.

1. What is this app?

When someone places an order on NepalCan, the order still needs people to make sure it goes smoothly:

  • Is the customer still serious about the order? → We call and ask.
  • Is the shop (vendor) going to send the product? → We call and remind.
  • Was the delivery okay? → We call and collect the customer's review.

This app gives the team a to-do list of calls. It tells you who to call, in what order, and what to ask — so nobody has to guess what's next.

2. Who can use it? (Roles)

There are two kinds of accounts:

RoleWhat they can do
Super Admin (boss / manager)Everything — sees all orders, creates staff accounts, assigns branches, resets passwords, opens the Users page.
Staff (caller)Sees the calls they need to make. They see orders that are not assigned to anyone yet, plus their own. They cannot see the Users page.
Remember: A staff member only sees the work they should be doing. If a job is assigned to someone else, it won't show in their list — that's on purpose.

3. The screens (what each one is for)

Use the menu bar at the top of the app to move around:

  • Today's Work — your dashboard. Shows the count of calls due today for each type, and the order list for today.
  • Next Call — the "one at a time" mode. Shows the single most urgent call. Pick an outcome (or add a note) and it automatically moves you to the next one.
  • Task Queues — all the call queues listed by type (Confirmations, Vendor calls, Review calls, Recoveries…).
  • Orders — every synced order, grouped into segments like Pending Confirmation, Pending Review Calls, Delivered Follow-up.
  • Recovery — orders that were cancelled but might be saved (recovery attempts).
  • Rules — the business rules that decide what kind of call gets created. Only change these if you know what you're doing.
  • Analytics — numbers and stats about tasks and performance.
  • Settings — time limits (SLA) for each call type.
  • Users — (super admin only) create staff accounts, pick their branch, activate/deactivate, reset passwords.

4. A typical day, step by step

Step 1 — Open Next Call

The app shows the one call that matters most right now. It tells you the order number and shows the phone number to dial.

Step 2 — Make the call

Press the phone number. Then record the outcome with one click:

  • Customer Confirmation call: Confirmed / Rejected / Tomorrow / Wrong number / No answer / Call later.
  • Vendor call: Reminded / Accepted / Delayed / Escalated.
  • Review call (delivered orders): collect the customer's review and save it (see section 6).
  • Cancelled order recovery: Recovered / Coupon offered / Express dispatch / Lost.

Step 3 — Add a note (optional)

Type anything useful in the note box — e.g. "Customer says they'll pick up from the store." Notes are saved on the task and appear in the order's detail page.

Step 4 — Move on

After you record the outcome, the app automatically loads the next call. Keep going until it says "All Calls Completed!"

5. What does the Sync button do?

The real order information lives in the main NepalCan system. The Sync button pulls the latest status of every order from there into this app.

What sync does and doesn't change:

  • It updates things like order status (Pending / Processing / Delivered / Cancelled), payment status, and amounts.
  • It keeps the team's own work — whether a customer confirmed, what the vendor said, notes, reviews — these are never deleted by sync.
  • If a status changed in the main system, sync records it in the order's Status History so you can see what changed and when.
Tip: If something looks out of date, press Sync and wait a few seconds. This is usually the first fix for "why doesn't this order look right?"

6. Notes & Reviews

Order notes

Open any order's detail page and scroll to Order Notes. Type a note and press Add. Notes from the main system and notes from your team all show here, oldest first.

Customer reviews (delivered orders)

Once a product is Delivered, we don't ask the customer to confirm the order again — instead we ask for a review:

  • Open the delivered order's detail page.
  • Press Call Customer & Get Review.
  • Type what the customer said about the delivery, then press Save Review.

The review is saved on the order and visible every time you open it.

7. For super admins — managing the team

Open the Users page:

  • Add User — create a staff account with email, password, team, and which branch they should see.
  • Deactivate / Activate — switch a staff member off without deleting them.
  • Reset Password — give a forgotten-password account a new password. (Only a super admin can do this.)

Branch names are not typed in — they are picked from the list of branches found in the orders, so the list is always accurate.
